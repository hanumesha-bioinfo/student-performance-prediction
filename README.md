# Student Performance Prediction Using Machine Learning

## Project Description

This project predicts whether a student will pass or fail using
machine learning.

## Machine Learning Algorithm

Logistic Regression

## Features

- Study Hours
- Attendance Percentage
- Previous Exam Score
- Assignment Score

## Target

- 0 = Fail
- 1 = Pass

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib

## Project Workflow

1. Load dataset
2. Check missing values
3. Remove duplicate records
4. Split data into training and testing sets
5. Preprocess the data
6. Train Logistic Regression model
7. Evaluate the model
8. Save the trained model
9. Predict student performance

## Dataset

The dataset used in this project is synthetic/illustrative data created
for educational purposes and does not represent real REVA student data.

python train_model.py
